Induced Backdoor Lateral Propagation

  • AI security
  • multi-agent
  • backdoors
  • threat models

Whether a behavioural backdoor planted in one agent spreads to the agents it talks to through ordinary interaction, and whether the resulting actions can be caught downstream. Built from scratch as a multi-agent harness with a rotating provider stack, run across baseline, dual-poison, aggressive, susceptible and ablation arms.

Detection results exist for the arms run so far. The open question is whether propagation survives when the receiving agent has no reason to trust the sender.

Belief State Geometry in Non-Ergodic Transformers

  • interpretability
  • representation geometry
  • transformers
  • pre-registered

Whether a transformer's residual stream makes the boundary between ergodic components visible, when it was only ever trained on one side of that boundary. Predictions were registered before the experiment ran.

Residual stream linearly encodes analytical belief states; four process-type clusters separate as context grows. Models trained on CW sequences map unseen CCW sequences onto the same manifold (r = 0.92–0.96, inter/intra-cluster ratio 1.005). The non-ergodic boundary is invisible to the learned representation.

Behavioural Override and the Boundary Probe

  • probing
  • finetuning
  • representation geometry

A follow-up: take the model from above, finetune it across the boundary with a forced behavioural override, and ask whether linear and non-linear probes degrade the same way. They do not.

20 seeds. Linear probe 0.800 → 0.769. MLP probe 0.861 → 0.851. Widening gap, bootstrap p = 0.0105. Narrow finetuning selectively degrades linear recoverability while the non-linear boundary information survives.

Temporal Dynamics and Spectral Signatures in LLM Activations

  • monitoring
  • hallucination detection
  • activations

Whether the spectral structure of activations over time carries a signal that static features miss. It does, for subtle hallucinations, and only in some architectures.

Spectral entropy improved hallucination detection in Gemma-2-2B and not in Qwen2.5. Static features stayed better for geometrically obvious failures; a limit on cross-architecture monitoring tools.
